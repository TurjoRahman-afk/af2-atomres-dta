# KNOWN CONFLICT — ESM-C vs ESM-2
#
# Two different projects publish a package that imports as `esm`:
#
#   esm==3.2.1.post1  (EvolutionaryScale)  -> esm.models.esmc  — used by
#                                             pretrained/esmC_pretraiend.py
#   fair-esm          (Meta)               -> esm.pretrained.esm2_*  — used by
#                                             pretrained/esm2_map.py
#
# They occupy the same import name and cannot be installed side by side.
# With the pin above, `esm.pretrained.esm2_t36_3B_UR50D` does NOT exist, so
# pretrained/esm2_map.py will fail. That script is only needed to generate
# ESM-2 contact maps for the AF2-vs-ESM-2 comparison; run it in a separate
# virtual environment:
#
#   python -m venv .venv-esm2
#   .venv-esm2/Scripts/activate      # Windows
#   pip install fair-esm torch pandas tqdm
#   python pretrained/esm2_map.py
#
# Both scripts write pickles, so the outputs are interchangeable afterwards
# and training runs in the main environment either way.
